# Crew Health Display

A client-side mod for Barotrauma that shows your crew’s health and status in a HUD panel.

Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3715230190) and enable the mod in-game. Version 2.2.1 supports Barotrauma 1.15.33.2 and requires [LuaCsForBarotrauma](https://github.com/Luatrauma/LuaCsForBarotraumaPlugin).

Starting with version 3.0.0, the mod loads through Barotrauma’s native plugin system and no longer requires LuaCs. The game may show a warning when you enable or update the mod.
